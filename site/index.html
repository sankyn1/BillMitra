Frequently Asked Questions

Got Questions? We Have Answers.

Everything you need to know about BillMitra's offline architecture, GST statutory compliance, and data security.

Does BillMitra require an active internet connection to create bills?

No. BillMitra is built with a 100% offline-first philosophy. Invoicing, inventory tracking, receipts, thermal printing, and ledgers work locally on your PC. Internet is only used when downloading updates or filing directly to GST portals.

Can I upload BillMitra's GSTR-1 file directly to gst.gov.in?

Yes. BillMitra outputs standard GST offline tool-compliant JSON files (GSTR1_GSTIN_Period.json) covering Table 4A (B2B), 5A (B2CL), 7 (B2CS), 9B (CDNR), 12 (HSN summary), and 13 (Docs issued). Simply upload the JSON file in the government portal.

Can I use pre-printed company letterheads?

Yes! BillMitra includes a dedicated "Pre-Printed Stationery Mode" with a configurable top margin gap (20mm to 100mm). It suppresses the supplier header box so that invoice lines and amounts print directly onto your pre-printed offset letterhead paper.

What database does BillMitra use?

BillMitra features a hybrid database engine: it includes an embedded SQLite database for immediate zero-configuration standalone use, as well as native support for Microsoft SQL Server / SQL Express and PostgreSQL for multi-PC networked setups.

Can I print on standard 80mm POS thermal receipt printers?

Yes. BillMitra includes built-in thermal slip templates formatted specifically for 80mm roll printers (Epson, TVS, NGX, Posiflex) with instant direct printing to the Windows Print Spooler without intermediate download dialogs.

Where is my business data stored?

All your customers, items, sales, and ledgers reside exclusively on your local computer or chosen local database server. No third party has access to your customer base, turnover, or pricing data.
